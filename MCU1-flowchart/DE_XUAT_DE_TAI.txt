8. NỘI DUNG NGHIÊN CỨU:
A. Phần 1: Nghiên cứu nền tảng
   - Tìm hiểu kiến trúc IoT: cloud, edge device, connectivity
   - Nghiên cứu ESP-IDF 5.0+, FreeRTOS, event loop system
   - Phân tích ESP RainMaker: device model, parameters, callbacks, MQTT
   - Học giao tiếp SPI (MFRC522), I2C (PCF8574, SSD1306), WiFi, Bluetooth

B. Phần 2: Thiết kế hệ thống phần cứng
   - Thiết kế sơ đồ kết nối: RFID (SPI), Keypad+OLED (I2C), Relay, Buzzer, Exit Button
   - Chọn linh kiện phù hợp: RC522, PCF8574, SSD1306, solenoid relay, active buzzer
   - Lập kế hoạch nguồn điện: 3.3V, 5V, 12V cho các module
   - Tối ưu hóa layout PCB (nếu làm PCB riêng) hoặc breadboard

C. Phần 3: Phát triển firmware
   - Lập trình driver RFID RC522: SPI communication, card detection, UID read
   - Lập trình driver Keypad: I2C to GPIO expand, button scanning, debouncing
   - Lập trình driver OLED: I2C display, menu system, real-time status
   - Xây dựng module NVS storage: lưu/đọc dữ liệu thẻ RFID
   - Cài đặt RainMaker device: tạo device type switch, parameters, device callbacks
   - Lập trình GPIO control: relay (output), exit button (input), buzzer (PWM)
   - Xây dựng event handler: RFID event, keypad event, WiFi event, RainMaker event

D. Phần 4: Tích hợp cloud và ứng dụng
   - Cấu hình WiFi provisioning: BLE + QR code (RainMaker standard)
   - Triển khai RainMaker client: node init, device register, MQTT publish/subscribe
   - Xây dựng push notifications: cảnh báo khi có lạ hoặc mở từ remote
   - Phát triển logic điều khiển: lệnh mở từ app → relay → auto-close
   - Lập trình thống kê: lưu nhật ký truy cập, tính số lần mở, người dùng thường xuyên

E. Phần 5: Kiểm thử và tối ưu
   - Unit test: từng module (RFID, keypad, relay, RainMaker)
   - Integration test: các module kết hợp
   - Performance test: độ trễ mở cửa, WiFi latency, power consumption
   - Security test: độ tin cậy xác thực RFID+password, replay attack
   - Long-term stability test: chạy 24/7 trong 1-2 tuần
   - Power optimization: giảm tiêu thụ khi ở chế độ idle/sleep

9. SẢN PHẨM, THÔNG SỐ KỸ THUẬT VÀ KẾT QUẢ DỰ KIẾN:

Sản phẩm chính:
1. Firmware ESP32-C3 hoàn chỉnh (C source code, modular, documented)
2. Phần cứng prototype: schematic, bill of materials (BOM)
3. RainMaker cloud integration: device model, parameters, push notifications
4. OLED UI: menu quản trị thẻ RFID, display nhật ký
5. NVS database: lưu dữ liệu thẻ/mật khẩu bền vững
6. Tài liệu: hướng dẫn lắp ráp, cấu hình, sử dụng
7. Code source trên GitHub: open-source, well-documented

Thông số kỹ thuật:
- Microcontroller: ESP32-C3 (160MHz, 320KB SRAM, 4MB Flash)
- Sensor: MFRC522 RFID reader (13.56MHz, SPI)
- Input: PCF8574 I2C GPIO expander (keypad 4x4), exit button GPIO
- Display: SSD1306 OLED 128x64 (I2C)
- Output: 8Ω relay + solenoid, buzzer (PWM), LED
- Connectivity: WiFi 802.11 b/g/n, Bluetooth LE 5.0
- Storage: 4MB Flash (firmware + NVS database)
- Độ trễ điều khiển:
  * Local (RFID+password): < 100ms
  * Remote (cloud): < 2 giây
  * Auto-close time: 3 giây (configurable)
- Tiêu thụ điện:
  * Active (khóa mở): ~ 200mA @ 5V
  * WiFi connected: ~ 80mA
  * Sleep mode: < 100μA

Kết quả dự kiến:
- Hệ thống hoạt động ổn định, tin cậy > 99.5% uptime
- Hỗ trợ ≥ 100 thẻ RFID được lưu trữ
- Xác thực đúng 100% với thẻ đúng + mật khẩu đúng
- Phát hiện 100% các lần nhập sai (trigger buzzer + app notification)
- Giao diện OLED hiển thị thời gian thực tức thời
- Nhật ký truy cập lưu 1000+ lần cuối (circular buffer)
- Offline hoạt động độc lập, tự sync khi online
- Tiêu thụ năng lượng tối ưu (< 500mAh/ngày với 100 lần truy cập)

PHỤ LỤC: KIẾN TRÚC HỆ THỐNG

1. Phần cứng:
   ESP32-C3 (MCU)
   ├─ SPI Bus → MFRC522 (RFID reader)
   ├─ I2C Bus → PCF8574 (keypad) + SSD1306 (OLED)
   ├─ GPIO 8 → Relay (door lock solenoid)
   ├─ GPIO 1 → Buzzer (PWM alert)
   ├─ GPIO 18 → Exit Button (input)
   └─ WiFi/BLE radio

2. Firmware Architecture (Event-driven):
   App Main Task
   ├─ Event Loop (RMAKER_EVENT, RMAKER_COMMON_EVENT, APP_NETWORK_EVENT)
   ├─ WiFi Task (background, provisioning)
   ├─ RFID Reader Task (continuous scan)
   ├─ Keypad Input Task (debounce + input handling)
   ├─ Display Task (OLED refresh, menu)
   └─ RainMaker Client (MQTT, cloud sync)

3. Data Structure:
   struct Card {
       uint8_t uid[4];
       char password[7];  // 6 digits + null
       char name[32];
       uint32_t access_count;
       bool is_active;
   } → stored in NVS with key-value pairs

   struct SystemStats {
       uint32_t total_opens;
       uint32_t rfid_success;
       uint32_t rfid_failed;
       uint32_t app_opens;
       uint32_t intrusions;
   } → persistent in NVS

4. Cloud Model (ESP RainMaker):
   Device Type: "Smart Lock"
   Parameters:
   - power (bool): lock state
   - password (string): current password input
   - access_log (string): recent access list
   - intruder_alert (bool): security alert
   - stats (string): system statistics
   
5. Workflow (RFID + Password):
   1. RFID reader detects card → read UID
   2. Query NVS for card record + required password
   3. Display "Enter Password" on OLED
   4. User input 6 digits via keypad (with * display)
   5. Compare with stored password
   6. ✓ Match: Activate relay 3s + green LED + success log
   7. ✗ Mismatch: Buzzer 3x beep + intruder alert + notification
   8. Cloud sync if WiFi available
